VANILLA GUI -> LDLIB CONVERSION LIST
====================================

Every Screen in Minecraft 1.21.1 + NeoForge 21.1.248 (taken from the decompiled sources: 117 screens;
Realms left out), grouped by where the player meets them, with what else in the game or the pack is
attached to each.

HOW TO MARK
  Put a letter inside the brackets in front of each entry:
    [N]  do it now
    [L]  later
    [X]  don't convert (stays vanilla)
    [R]  Removal. (hide)
  [DONE] = already converted.
  You can also mark the BUILDING BLOCKS in section 0 -- they decide how cheap the screens after them are.

SIZE  (rough, relative)
  S  a static screen: text + a few buttons / fields
  M  a list, a few interactive parts, or a custom drawing (book, sign, entity preview...)
  L  a complex widget (tree, editor, tabbed form), heavy logic, or many mods hooked into it

FLAGS
  (hidden)  not reachable in the pack as it is now (e.g. the Singleplayer button is removed from the
            title screen) -- converting these changes nothing a player sees.
  (hooks)   roll_mod or other mods already attach things to this vanilla screen; a conversion has to
            carry them over, or they disappear (same as other mods' buttons on the old title screen).

HOW A CONVERSION WORKS (same as the title and server list)
  The vanilla screen is swapped for an LdLib one as it opens (ScreenEvent.Opening). The game logic
  under it is reused, not rewritten: server list file, pinger, menus/slots synced by vanilla, etc.
  Anything that only exists inside the vanilla class (connection thread, sign text sync...) is either
  kept by drawing over the vanilla class instead of replacing it, or reached through a small mixin
  accessor (as JoinMultiplayerScreenAccessor does).


------------------------------------------------------------------------------------------------------
0. BUILDING BLOCKS  (one-off pieces; each one makes a whole group below cheap)
------------------------------------------------------------------------------------------------------
[ ] B1  Message / confirm dialog template                                                      S
        Title, text, 1-3 buttons, optional progress bar / cancel. Covers ~20 screens in sections 2,
        3, 9, 10 (Confirm, Alert, Error, Disconnected, Generic message/waiting, Progress...).
[ ] B2  Option list renderer                                                                   M
        Renders vanilla OptionInstance values (toggle / cycle / slider) as themed LdLib rows.
        Almost every Options sub-screen is just a list of these -> ~10 screens become S.
[ ] B3  Container screen shell                                                                 M-L
        LdLib screen on top of the vanilla menu (slots, sync and server logic stay vanilla).
        Must keep EMI/JEI working (exclusion areas, recipe transfer, item under mouse), keep the
        recipe book, and keep roll_mod's container hooks (title colour, money shoving...).
        Needed before anything in section 5.
[ ] B4  Text-entry editor                                                                      M
        Multi-line text editing with cursor/selection for book / sign / command block screens.
