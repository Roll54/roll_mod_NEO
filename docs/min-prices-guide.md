# Мінімальні ціни: проста інструкція

Мінімальна ціна — найменша сума в старкоїнах, за яку предмет можна продати іншим гравцям: на аукціоні
чи в торговому блоці. Вона потрібна, щоб ніхто не обвалював ринок, продаючи речі майже даром.

Ціни ніхто не вписує вручну: сервер **сам рахує їх з рецептів гри**, починаючи від сирих руд. Що більше
ресурсів і роботи йде на предмет, то дорожчий він.

Технічні подробиці — у [min-prices.md](min-prices.md).

---

## Для гравців

### Де побачити ціну

Наведи на будь-який предмет — у підказці буде рядок **«Мін. ціна: N старкоїнів»**. Для стаку видно ціну
за штуку і за весь стак разом. Для рідин в EMI ціна вказана за 1000 mB (одне відро).

### Що буде при продажу

- **Аукціон:** лот не можна виставити дешевше за мінімальну ціну (для ставок — стартову ціну).
- **Торговий блок:** позицію не можна створити з ціною, нижчою за мінімальну.
- Якщо мінімальна ціна згодом **зросла**, а позиція в торговому блоці лишилась дешевшою, вона
  **вимикається**, доки власник не підніме ціну.
- Жоден предмет не продається дешевше за **абсолютний мінімум** (за замовчуванням 1 старкоїн за
  штуку), навіть якщо з рецептів виходить менше.

### Повідомлення

| Повідомлення | Що означає |
|---|---|
| «…не можна виставити дешевше за N старкоїнів» | Підніми ціну хоча б до N. |
| «Мінімальні ціни ще обчислюються» | Сервер щойно запустився або перераховує ціни. Зачекай трохи. |
| «Ця пропозиція дешевша за мінімальну ціну сервера і вимкнена» | Власник торгового блоку має підняти ціну. |

### Дерево рецептів: звідки береться ціна

Щоб зрозуміти, з чого складається предмет і скільки базових ресурсів на нього йде, відкрий
**дерево рецептів**. Воно саме ціни не змінює, але показує той самий ланцюжок рецептів, з якого сервер
рахує ціну.

1. Введи `/recipetree` (потрібен EMI).
2. Перетягни предмет зі списку EMI у слот угорі меню. Коліщатко над слотом змінює кількість (із
   Shift — по 10), ПКМ очищає.
3. Обери рецепти:
   - **«Авто»** — сам обере найпростіший рецепт для кожного інгредієнта, аж до базових ресурсів;
   - **клік** по предмету — відкриє його рецепти в EMI, обери потрібний кнопкою біля рецепта;
   - **Shift+клік** — EMI сам обере рецепт для цього предмета;
   - **ПКМ** — прибрати рецепт, предмет стане базовим ресурсом.
4. Внизу, у рядку **«Базові ресурси»**, — усе, що треба добути. Цифра на предметі — скільки його
   потрібно.

Жовта рамка — рецепт є, але не обраний. Червона — предмет уже крафтиться вище в дереві. Дерево
рухається мишкою, коліщатко над ним змінює масштаб, «Скинути» прибирає всі обрані рецепти. Вибір
тримається, поки гра відкрита.

## Для адміністраторів

### Увімкнути

Конфіг `config/min_price.json5` (можна редагувати і з гри, рівень доступу 4). Головний вимикач —
`enabled`. Після будь-якої зміни з гри ціни перераховуються самі.

### Як сервер рахує ціну (коротко)

1. **Сирі руди** коштують фіксовано, за рівнем виміру (`tiers`, `oreTiers`): у звичайному світі
   дешевше, на далеких планетах дорожче.
2. Ціна рецепта = сума цін його інгредієнтів × множник типу рецепта (робота й енергія машини).
3. Якщо предмет можна зробити кількома рецептами, береться **найдорожчий**, хіба що ти вказав інший
   у `itemRecipes`.
4. Предмет, який ніщо не крафтить, коштує абсолютний мінімум.

Перерахунок відбувається на старті сервера, після `/reload`, після зміни конфігу з гри і за командою
`/rollmod minprice rebuild`.

### Команди (рівень доступу 2)

| Команда | Що робить |
|---|---|
| `/rollmod minprice hand` | Ціна предмета в руці: звідки вона взялась, за яким рецептом, і всі рецепти з ціною за кожним. |
| `/rollmod minprice item <предмет>` | Те саме для будь-якого предмета. |
| `/rollmod minprice dump` | Уся таблиця у файл `minprice_dump.json`. |
| `/rollmod minprice rebuild` | Перерахувати зараз. |

### Як виправити ціну

| Проблема | Що зробити |
|---|---|
| Ціна завелика | `/rollmod minprice item <предмет>` → подивись, який рецепт виграв. Вкажи дешевший у `itemRecipes` або додай дорогий у `recipeBlacklist`. |
| Ціна 1, хоча мала б бути більша | Предмет не має рецептів, які сервер зміг прочитати. Задай ціну вручну в `itemWhitelist`. |
| Предмет не повинен мати ціни | Додай його в `itemBlacklist` (абсолютний мінімум усе одно діє). |
| Побічний продукт рецепта занадто дорогий | Постав йому в `outputWeights` число менше 1. |
| Нова руда | Додай її в `oreTiers` з рівнем виміру. |
| Ціна рідини | `fluidWhitelist`: рідина → ціна за відро. |

Приклад вибору рецепта:

```json5
itemRecipes: {
  "minecraft:iron_ingot": "minecraft:iron_ingot_from_smelting_raw_iron",
  "#c:ingots/copper": "minecraft:copper_ingot_from_smelting_raw_copper"
}
```

Ключ — id предмета, `#тег` або `fluid:<id рідини>`, значення — id рецепта. Id рецептів видно в
`/rollmod minprice item <предмет>`.

### Інші налаштування

- `absoluteMinPrice` — найнижча ціна одного предмета (і одного відра рідини). За замовчуванням 1.
- `allowFreePositions` — дозволити позиції торгового блоку з ціною 0 (роздачі).
- `blockSalesUntilReady` — забороняти продаж, поки ціни ще рахуються.
- Право LuckPerms `rollmod.minprice.bypass` знімає всі перевірки мінімальної ціни для гравця або групи:
  `/lp group admin permission set rollmod.minprice.bypass true`.
